# Lectura incremental de fronteras independientes certificadas

Para cada frontera nueva, comenzando en τ32, se leerá exclusivamente el estado extraído y auditado de su cápsula permanente. Se verificarán identidad, SHA256, catorce fuentes y tiempo. No se usa el recibo mutable del tramo siguiente ni resultados de ejecutores anteriores.

Se reconstruirán las matrices de Gram del espacio de fases del núcleo a partir de las respuestas ya guardadas y de su base angular original; se leerán las dos matrices k>4 del núcleo y ventana suave. Se emplearán exactamente las funciones metrics y sufficient, agrupaciones y criterios del lector final original. Las métricas individuales recalculadas deberán coincidir con las registradas. Se publicarán canales, grupos, cancelaciones y fracciones espectrales originales; no se integran campos ni observadores nuevos.

El resultado es provisional por tiempo y no sustituye la lectura final prerregistrada. No se calculan comienzos respecto de una norma final aún desconocida, no se evalúa aceptación física ni se declara una causa suficiente final o CP12 cerrado. Se conservan también las clases que fallan. Los resultados ya registrados no se sobrescriben.
