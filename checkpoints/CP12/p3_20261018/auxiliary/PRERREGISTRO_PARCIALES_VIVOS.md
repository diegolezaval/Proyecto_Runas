# Parciales redundantes fuera de las extracciones

El inventario pasivo preservado registra acumulación adicional en transport, capsules y staging, con nombres temporales ajenos a la captura canónica. Su origen permanece NO IDENTIFICADO. V2 conserva su código y alcance. Esta ampliación separada no toca código activo, NPZ actual, temporal actual sin sufijo aleatorio, configuración, fronteras, negativos ni ZIP canónicos.

Se permite representar reversiblemente sólo parciales redundantes, con nombre temporal limitado y dentro de esas tres ubicaciones. Se exigen firma estable observada durante60s, antigüedad de mtime y ctime≥300s, ausencia de enlaces y comparación de TODOS sus bytes con una fuente conservada. Las fuentes son ZIP canónicos ya recuperados/auditados, una entrada de transporte de esos ZIP, o un parcial local más largo que se retiene intacto. Las fuentes locales de cada pasada nunca se seleccionan para retirada en esa misma pasada. Ningún contenido único desconocido se descarta.

Antes de retirar cada redundancia se conserva un recibo inmutable con SHA, longitud, ruta, firma, fuente y receta exacta. Si una fuente parcial obtiene más tarde una representación, su SHA enlaza los recibos para reconstrucción transitiva. Una fuente parcial no constituye un estado científico válido. Los archivos canónicos siguen conservados local y permanentemente. El auxiliar tiene bloqueo propio, no invoca Library/M2 y termina al observar la salida propia científica. Un desacuerdo sólo detiene este auxiliar y conserva los archivos restantes.

Primero se publican código/registro; después se contrastan protección de rutas, desconocidos, estabilidad, anclas locales y reconstrucción desde ZIP. Se conserva una selección en seco real antes de activarlo. Esto reduce redundancia pero no resuelve por sí solo el crecimiento de parciales únicos: si se acumulan, se requerirá preservarlos y recuperarlos permanentemente antes de retirar cualquier copia local. No se modifica una puerta para resolver espacio.
