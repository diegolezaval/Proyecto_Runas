## Ruta y razón

Se mantiene GitHub Releases como destino definitivo. Se añade una sola cápsula temporal en la Biblioteca, escrita, descargada en una raíz nueva y auditada desde el proceso de cálculo, usando únicamente los ayudantes actuales de transferencia. Después se adjunta el mismo ZIP a la Release existente desde la sesión de GitHub del navegador y se descarga públicamente para otra auditoría independiente.

La copia temporal debe estar guardada y recuperada antes de depender de una acción posterior del chat. Si el control se interrumpe antes del paso de GitHub, sus bytes quedan identificados en un archivo persistente y no se reconstruyen desde hashes ni se repite el tramo. No se autoriza más física hasta que GitHub contenga una copia íntegra recuperada y auditada. Sólo se elimina una copia temporal propia después de comprobar el respaldo definitivo; se conserva su recibo y no se tocan originales ni la transferencia histórica 116/308.
